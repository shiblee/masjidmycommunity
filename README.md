# My Project

Basic Node.js + React starter.

## Structure

- `server/` — Express backend (API on port 5000)
- `client/` — React frontend (Vite, dev server on port 5173)

## Setup

### Server

```bash
cd server
npm install
npm run dev
```

Update `server/.env` with your own `MONGO_URI` and `JWT_SECRET`.

### Client

```bash
cd client
npm install
npm run dev
```
